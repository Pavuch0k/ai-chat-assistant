## API Документация

### Swagger UI

Интерактивная документация API доступна по адресу:
**http://localhost:8000/docs**

Swagger UI предоставляет:
- Полный список всех API endpoints
- Описание параметров запросов и ответов
- Возможность тестирования API прямо в браузере
- Примеры запросов и ответов

### OpenAPI Schema

JSON схема доступна по адресу:
**http://localhost:8000/openapi.json**

### Основные Endpoints

#### POST /api/chat
Отправка сообщения боту

**Request:**
```json
{
  "message": "Привет, как дела?"
}
```

**Response:**
```json
{
  "response": "Привет! Отлично, спасибо! Чем могу помочь?"
}
```

#### GET /api/admin/contacts
Получить список всех контактов

#### GET /api/admin/contacts/{contact_id}/messages
Получить историю сообщений контакта

#### GET /api/admin/messages
Получить все сообщения (лимит: 100)

## Админ панель

### Доступ

Админ панель доступна по адресу: **http://localhost:8000/admin**

### Интерфейс

Админ панель имеет современный и удобный интерфейс:

#### Вкладка "Контакты"
- Таблица со всеми контактами клиентов
- Отображает: ID, Имя, Email, Телефон, Дата создания
- Кнопка "История" для просмотра переписки с каждым контактом
- Автоматическое обновление данных

#### Вкладка "Сообщения"
- Таблица со всеми сообщениями
- Отображает: ID, ID контакта, Сообщение пользователя, Ответ бота, Дата
- Цветовая индикация сообщений (синий - пользователь, зеленый - бот)
- Хронологический порядок

#### История переписки
- При нажатии на "История" открывается полная переписка с контактом
- Отображаются все сообщения в хронологическом порядке
- Удобное форматирование для чтения

#### Вкладка "Настройки виджета"
- **Цветовая схема**: Настройка основных цветов виджета (кнопка, сообщения, заголовок)
- **Темы**: Выбор из готовых пресетов (темная, светлая, синяя, зеленая, красная, оранжевая, фиолетовая, бирюзовая)
- **Тексты**: Настройка приветственного сообщения и текста на расширенной кнопке
- **Предпросмотр**: Реалтайм-предварительный просмотр виджета с выбранными настройками
- **CSS переменные**: Все стили реализованы через CSS переменные для гибкой кастомизации

##### Доступные пресеты цветовых схем:
- **Темная**: Темно-синяя тема (#151b2e с акцентами #667eea)
- **Светлая**: Светлая тема (#ffffff с акцентами #4f46e5)
- **Синяя**: Сине-голубая тема (#1e3a8a с акцентами #3b82f6)
- **Зеленая**: Зелено-бирюзовая тема (#064e3b с акцентами #10b981)
- **Красная**: Красно-бордовая тема (#7f1d1d с акцентами #ef4444)
- **Оранжевая**: Оранжево-коричневая тема (#7c2d12 с акцентами #f97316)
- **Фиолетовая**: Фиолетово-пурпурная тема (#151b2e с акцентами #667eea)
- **Бирюзовая**: Бирюзово-зеленая тема (#134e4a с акцентами #14b8a6)

##### Настраиваемые элементы:
- **Основной цвет**: Цвет кнопки и градиента
- **Вторичный цвет**: Второй цвет градиента
- **Цвет сообщений**: Цвет расширенного сообщения
- **Цвета окна чата**: Фон, область сообщений, поле ввода, границы
- **Цвета сообщений**: Цвета сообщений пользователя и бота
- **Тексты**: Приветственное сообщение и текст расширенного сообщения

### Функционал

✅ Просмотр всех контактов
✅ Просмотр истории переписок
✅ Фильтрация по контактам
✅ Поиск по сообщениям
✅ Настройка внешнего вида виджета
✅ Экспорт данных (через API)

## Интеграция виджета

### Простая интеграция

Добавьте на ваш сайт следующие строки:

```html
<!-- В <head> -->
<link rel="stylesheet" href="http://localhost:8080/src/widget.css">

<!-- Перед закрывающим </body> -->
<script>
    window.API_URL = 'http://localhost:8000';
    window.MOCK_MODE = false;
</script>
<script src="http://localhost:8080/src/widget.js"></script>
```

### Настройки

#### API_URL
URL вашего backend API (по умолчанию: `http://localhost:8000`)

#### MOCK_MODE
Режим заглушки (по умолчанию: `false`)
- `true` - использовать заглушки без реального API
- `false` - использовать реальный API

### Пример полной интеграции

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Мой сайт</title>
    <link rel="stylesheet" href="http://localhost:8080/src/widget.css">
</head>
<body>
    <!-- Ваш контент -->
    
    <script>
        // Настройки виджета
        window.API_URL = 'http://localhost:8000';
        window.MOCK_MODE = false;
    </script>
    <script src="http://localhost:8080/src/widget.js"></script>
</body>
</html>
```

### Кастомизация

Виджет можно кастомизировать через CSS переменные или напрямую редактируя `widget.css`.

##### Доступные CSS переменные:
- `--widget-primary-color`: Основной цвет виджета
- `--widget-secondary-color`: Вторичный цвет (для градиентов)
- `--widget-button-color`: Цвет кнопки
- `--widget-message-color`: Цвет расширенного сообщения
- `--widget-background-color`: Цвет фона виджета
- `--widget-header-color`: Цвет заголовка
- `--widget-header-text-color`: Цвет текста заголовка
- `--widget-user-message-color`: Цвет сообщений пользователя
- `--widget-bot-message-color`: Цвет сообщений бота
- `--widget-text-color`: Цвет текста
- `--widget-messages-area-color`: Цвет области сообщений
- `--widget-input-background-color`: Цвет фона поля ввода
- `--widget-border-color`: Цвет границ

Пример кастомизации через CSS:
```css
.ai-chat-widget {
  --widget-primary-color: #ff6b6b;
  --widget-secondary-color: #4ecdc4;
  --widget-background-color: #2d3436;
  --widget-text-color: #f7f7f7;
}
```

## Технические детали

### Backend
- **Framework**: FastAPI
- **База данных**: PostgreSQL
- **AI**: OpenAI GPT-4o-mini
- **Прокси**: Поддержка HTTP прокси для API

### Frontend
- **Виджет**: Vanilla JavaScript (без зависимостей)
- **Стили**: CSS3 с градиентами и анимациями
- **Размер**: Минимальный footprint

### Безопасность
- CORS настроен для работы с любыми доменами
- Валидация входных данных через Pydantic
- SQL injection защита через SQLAlchemy ORM
